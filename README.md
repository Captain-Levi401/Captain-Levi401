### 🏢 TradeOS — Enterprise B2B Trust & Commerce Platform
 
`Java (Spring Boot)` `React.js` `PostgreSQL` `MongoDB` `Redis` `AWS`
 
A 6-layer distributed platform with escrow payments, multi-level verification, and a reputation engine.
 
- ⚡ Redis cache-aside with TTL invalidation → latency cut from **~120ms to ~1ms** (100–150x)
- 🔄 Least-connections load balancer with health-check failover → **99.98% uptime** through live instance failure
- 📐 OpenAPI-documented REST APIs for GST/PAN/bank verification, with backward-compatible versioning
- 💰 Escrow payment flows with concurrent transaction handling and dispute resolution
- ☁️ Deployed on AWS EC2 + S3 + Lambda
